# Proposed pilot after the hackathon

This is a proposal to discuss, not an agreed partnership or a commitment from
Ripple or any organiser. No outreach has been sent.

## The proposition in simple words

People agree using private documents, while the money movement happens in a
different system. Recognitium connects the exact agreement to that movement so
both sides can check the same history afterward.

The weekend demonstration uses test funds and synthetic documents. The pilot
would ask whether another team can integrate that connection easily and whether
the resulting evidence answers a real question they currently struggle with.

## A small, testable collaboration

Ask for one engineering counterpart and one concrete workflow selected together.
Offer the working reference integration, setup instructions, observed developer
friction and a reproducible evidence bundle. Start on the development network.
Agree duration, responsibilities and any commercial terms only after scoping.

Success would mean:

- Their developer completes the documented cycle from a clean environment.
- The agreement version, both approvals and validated transaction can be linked.
- A changed document is detected and a missing receipt can be recovered without
  initiating another loan.
- The team measures integration effort and how long it takes to resolve a
  selected evidence question, compared with its current workflow.
- Both sides identify whether there is a useful next deployment or no reason
  to continue. Set numerical targets jointly before running the pilot.

## Suggested closing invitation

"We have a concrete integration to test with you. Give us one workflow where
people struggle to connect an agreement to a transaction, and let's evaluate
whether Recognitium makes that connection easier to check."

Use the first sentence only when the integration actually works. Lead the event
presentation with the demonstrated flow and reproducible feedback. The pilot
invitation follows that evidence. Do not describe organisers as partners until
they have explicitly agreed.
